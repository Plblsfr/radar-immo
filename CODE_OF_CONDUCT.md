# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/). En voici l'essentiel.

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience sans harcèlement pour tout le monde, quels que soient l'âge, la taille, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Comportements attendus

- Faire preuve de bienveillance et de respect.
- Accueillir les points de vue et les expériences différents.
- Donner et recevoir des critiques constructives avec élégance.
- Assumer ses erreurs et en tirer des leçons.
- Privilégier ce qui est le mieux pour la communauté.

## Comportements inacceptables

- Langage ou images à caractère sexuel, avances non sollicitées.
- Trolling, insultes, attaques personnelles ou politiques.
- Harcèlement public ou privé.
- Publication d'informations privées d'autrui (adresse, téléphone…) sans autorisation explicite. Cela vaut aussi pour les coordonnées de vendeurs ou d'agences trouvées dans des annonces.
- Tout comportement raisonnablement considéré comme inapproprié dans un cadre professionnel.

## Application

Les mainteneurs peuvent retirer, modifier ou refuser tout commentaire, commit, issue ou contribution qui ne respecte pas ce code, et exclure temporairement ou définitivement un participant.

Pour signaler un comportement, utilise le signalement privé de GitHub (*Security → Report a vulnerability*, en précisant « Code de conduite »), ou contacte directement un mainteneur. Tous les signalements sont traités de manière confidentielle.
